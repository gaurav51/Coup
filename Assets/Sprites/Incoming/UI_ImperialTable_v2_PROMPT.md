# Imperial table background

Built-in image generation edit using the user's Futuristic Imperial Strategy Game Table.png as the visual reference. Opaque output saved in 02_Backgrounds/UI_ImperialTable_v2.png so the project's automatic background importer preserves full resolution.

Prompt: Reconstruct only the empty imperial chamber and black marble circular gaming table from the reference. Preserve warm gold lighting, brass concentric rings, distant city windows, crimson/purple/amber banners, leather seating and plants. Remove all player badges, cards, portraits, decks, coin piles, counters, panels, buttons, icons and text. Quiet tabletop center with a restrained gold compass inlay; bottom quarter dark and low detail. No writing, UI, characters, cards, coins or watermark. Full-bleed portrait realistic digital painting.

The live frames, rings and circle masks are native UI geometry PNGs made through Unity, rather than generated artwork. FrameFill and FrameLine use 28px slice borders so corner proportions are fixed at different panel sizes. Player portraits reuse existing approved art cropped through circular masks. All names, rules, counts, prompts and influence markers remain live Unity UI.
